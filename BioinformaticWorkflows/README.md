# Workflow Orchestration
Bioinformatic uses cases were undertaken because their related data structures, and algorithms map directly to ETL pattern due to standardized workflows and datasets (Li et al., 2009; Van der Auwera et al., 2002). Sequencing datasets are also large, for instance the raw compressed sequence data for a human genome is ~240GB and typically require a collection of reference datasets for processing. Meaning that there are environment requirements for deploying these workflows, that are resource intensive, and with variable wall times, a pilot job processing a collection of tasks over its lifecycle is more efficient approach than managing large volumes of sporadic job arrays. Furthermore, since sequencing data procurement can be a burden, sample tracking throughout their data lifecycle is important. Projects with such requirements are a good fit for TaskTide. In conjunction with sample meta-data database, TaskTide was used to orchestrate this on a HPC environment within Sonic allocation at UCD using RocksDB backend. Supporting software external to TaskTide are provided within the TaskTide repository.
