# Containerized Deployment
<p id="container">
The purpose of this use case was to assess the application of TaskTide to AI Data Application Layer deployments in a containerized Infrastructure Layer, supported by a networked database solution. The workflow TaskTide orchestrates is an open-source autonomous player interfaces for SNES emulator for optimizing Super Mario Brothers playtimes (Farama Foundation, 2023; Kautenja, 2025; Shams & Elsheikh, 2023). For these late task binding case, the distinct inputs represent different experiments each training their own AI agent from a variable level input within Super Mario. The outputs were then mapped into the second step of the workflow, which applied the trained model with observational data was collected to evaluate the AI agent’s performance in playing Super Mario (i.e train and play workflow). Lastly, a third and final step aggregated these metrics and performed a simple analysis over the results to rank AI agents by their performance.
</p>

<p id="container-1">
The collective 3 step workflow along with its deployment onto EOSC container platform, demonstrate the utility of TaskTide in orchestrating the deployment of Data Application Layer workflows across Infrastructure Layer. Where an AI agent was developed in a general manner, to facilitate scale out. In this specific instance, the data generated by the AI agent is costly due to the computational workload. TaskTide offers a transparent solution for such introspection requirements. As individual tasks across, each step can be tracked and monitored over their lifecycle and additionally mapped to their execution context. Supporting software external to TaskTide are available within the TaskTide repository.
</p>
